## ⑩ 多人对话（客户经理 + 客户 + 采购）
> 标签：对话识别｜账期+欠款｜比价｜质量反馈
> 多人对话实测：DeepSeek 能正确区分"谁说的"，识别出 加量2吨 / 30天账期 / 3.5万欠款 / 温氏18.6 / 色泽出成率问题，并生成对应待办。

```
客户经理小王回访南阳批发客户张老板，店里采购小李也在场。
小王：张老板，上次那批白条走货怎么样？
张老板：走货还行，就是损耗比我想的高一点。
小李：主要是最后那两天到货的，色泽有点暗，出成率低了些。
张老板：小王你也别光听好话，上次说好的30天账期，怎么还没批下来？我们这边一直想续量，你这个月能不能把量加到两吨？
小王：账期的事我回去再跟公司确认，您放心。不过咱们上次那三万五的货款还没结，张老板您看这周能不能先结一部分？
张老板：最近手头确实紧，等月底客户回款了我就结，不骗你。
小李：对了王哥，温氏那边白条报18.6，还给30天账期，你们公司能不能也按这个价走？
小王：价格我可以再谈，但我们的品质和到货稳定摆在这。您先按主销规格做个试单，我下周先把配送时效的对比数据给您送过来。
张老板：行，那这个月先把量加到两吨，你尽快把报价单发我，账期的事一起落实。
```

## ⑪ 双人对话 · 新客开发（餐饮 · 比价+账期+试单）
> 适合测：找客户相似案例、比价表、账期识别、推荐话术。

```
客户经理小王首次拜访郑州餐饮连锁客户李总。
小王：李总您好，我是咱们这边的客户经理小王，之前电话约过您，今天来拜访一下。
李总：坐坐坐。我们最近要上一批分割品，之前一直用别家供应，主要是担心出成率和到货稳定。
小王：理解，餐饮最怕这两个。您这边一周大概走多少分割品？
李总：一周两百公斤左右，做快餐要规格稳定。对了，你们这边能不能给账期？我们一般月结。
小王：账期我可以帮您跟公司申请，新客户首月一般现款，稳定合作后可以谈月结。价格上您有对比过吗？
李总：别家报价分割品20.4，还答应送两周账期。你们能做到多少？
小王：价格我可以给您报20.8左右，但我们规格稳定、到货准时。您先拿一个主销规格做小批量试单，看看损耗和出成率，再决定长期合作。
李总：行，那先试一批，配送时效您给我保证下。
```

张老板：走得还行，你们上次那批白条损耗低，客户反馈不错。这个月我想再加量，加到两吨。

## ⑬ 双人对话 · 质量投诉（赔付整改 · 售后闭环）
> 适合测：投诉处理、风险提醒、售后回访恢复合作。

```
客户经理小王回访洛阳商超客户王店长，处理上周白条客诉。
小王：王店长，今天来是为了上周那批白条的事，实在不好意思。
王店长：你来了正好，那批白条色泽发暗、出成率低，我损失不小。你再这样，我只能换供应商了。
小王：我理解您的损失。我已经调了那批的批次记录，今天约了品控一起到现场核实，核实完按流程给您赔付和补货方案，最晚这周五给您答复。
王店长：周五可以，但我要白纸黑字写清楚，下次再出问题怎么处理。
小王：没问题，我把赔付标准、补货时效和下次的质量承诺都写进协议。另外这周五我送一批新到的白条给您先试，看看品质。
王店长：行，你要是真能做到，我们下个月的活动促销还可以继续合作。
小王：那就这么说定了，周五我过来，顺便把促销合作的方案也带过来。
```

## ⑭ 报价·账期多轮拉锯（批发 · 18 轮）
> 标签：报价比价|账期谈判|授信|试单｜测：竞品比价、账期条件、综合价差、风险识别。

```
客户经理小王拜访批发客户李老板，谈下个月白条供货。
小王：李老板，今天来是想跟您谈谈下个月白条的供货。您这边上月走了300公斤，这个月能稳定多少？
李老板：稳定量得看价格。温氏那边给我报18.4，你们要是能到18.2，我一个月拿400公斤没问题。
小王：18.2说实话做不了，白条现在成本摆在那。18.6我能给您争取，但量要到500公斤以上。
李老板：18.6比温氏贵两毛，我凭什么选你？除非账期给到月结30天。
小王：账期30天我们新合作一般不放，最多15天，授信10万以内。账期越长其实越贵，资金成本算进去，18.6加15天账期未必比温氏18.4现款吃亏。
李老板：那你们品质到底比温氏好在哪？上次别家送来的白条有腥味，客户投诉好几回。
小王：这正是我要说的——我们白条从宰杀到出厂全程冷链，出厂前逐批检测，腥味注水基本不会出。您先拿200公斤试一周，损耗和口感对比一下。
李老板：试可以，但价格按18.5，账期15天，试单一周内不满意我随时停。
小王：行，18.5我回去跟主管申请，试单200公斤、账期15天、授信先按5万。一周后拿数据说话。
```

## ⑮ 新客开发·层层异议（餐饮连锁 · 14 轮）
> 标签：新客开发|异议处理|试单|配送承诺｜测：相似案例、话术、待办、账期识别。

```
客户经理小王首次拜访餐饮连锁客户李总，李总顾虑很多。
李总：你们公司我不太熟，之前也没合作过，怎么敢把一周两百公斤的量交给你们？
小王：理解，新供应商确实要谨慎。我先给您看看我们服务连锁餐饮的案例——郑州有家快餐连锁，之前也是担心这些。
李总：案例是案例，价格呢？我们现在用的分割品20.2，你们报多少？
小王：20.6。但我建议别只看单价，出成率差1%一公斤就差两毛多。
李总：出成率谁说了算？你们的货到了我店里，损耗算谁的？
小王：所以我才建议先小批量试单，50公斤试一周，损耗、出成率、到货时间您自己测，数据说话。
李总：试单可以，但我丑话说前头——配送迟到一次，这周的量我就不收了。
小王：可以，我们把配送时效写进协议，迟到赔付。您看试单这周四送还是下周一送？
李总：周四吧，赶得上周末高峰。对了，结算怎么算？
小王：试单先现款，稳定合作一个月后可以申请月结。您放心，账期是谈出来的，前提是量起来。
```

## ⑯ 滞销品承接（商超 · 促销试销）
> 标签：滞销承接|试销|回收承诺|促销｜测：找客户滞销品承接、风险提醒。

```
客户经理小王拜访商超王店长，推荐一批临期分割品。
王店长：今天又给我推什么？上次那批库存我还没消化完呢。
小王：店长，这次不是硬推。我们仓里有批分割品还剩2天保质期，价格能到七折，适合您促销引流。
王店长：七折是诱人，但卖不完全砸我手里，损耗谁赔？
小王：所以我只建议您拿80公斤，按您平时日销走，大概一天半能清完。卖不完的部分我们回收，白纸黑字写清楚。
王店长：那你给我什么促销支持？光打折我不划算。
小王：我这边可以申请促销海报物料，再配一个周末特价档期，您算下来毛利还是有保障的。
王店长：行，那先80公斤试试，周五到货，卖不完你负责回收。
小王：成交，我周五早上亲自送过来，顺便跟您对一下下周的新品报价。
```

## ⑰ 质量投诉深度处理（赔付谈判 · 16 轮）
> 标签：质量投诉|赔付|违约承诺|售后闭环｜测：投诉处理、P0待办、风险提醒、话术。

```
客户经理小王处理批发客户张老板的白条质量投诉。
张老板：小王，你来得正好，上周那批白条出大问题了！到货就发暗，切出来还有异味，我客户当场退了三单。
小王：张老板别急，我马上处理。您先别下架，我拍照留样，把批号发我。
张老板：还留什么样？我损失已经好几千了，你们要是不赔，这生意没法做了。
小王：我理解您损失。我半小时内把情况报给品控，今天派人到您店里现场核实，如果确认是我们的问题，按合同1:1赔付，另补一批好的给您。
张老板：1:1赔付，那我的误工和客户流失怎么算？我客户退单，丢的是信誉！
小王：张老板，误工这块我做不了主，但我能帮您申请额外补偿，比如下一批价格让5%，帮您把客户稳住。
张老板：让5%太少，最少8%，而且必须在周五前到货，我要赶上周末的订单。
小王：8%我回去跟主管争取，周五前到货我现在就排。如果没做到，我再给您让3%作为违约金，白纸黑字写进协议。
张老板：好，那就这么说。这次处理利索，我们后面还能继续合作，不然……
小王：放心，我把这个当第一优先级处理，周五给您结果。
```

## ⑱ 农贸档口配送（新客户 · 时效承诺）
> 标签：农贸|配送时效|迟到赔付|分割加工｜测：区域识别、配送承诺话术、待办。

```
客户经理小王拜访农贸档口刘姐，谈白条配送合作。
刘姐：你是卖白条的吧？我这档口一个月走两百公斤，都是早上6点前要货。
小王：刘姐您好，6点前到货没问题，我们配送车凌晨发车，5:40前能送到您档口。
刘姐：说得轻巧，上次别家说好6点，结果8点才到，我早市全耽误了。
小王：我理解，配送准时我们写在协议里，迟到一次当次货款打九折。您可以先试一周。
刘姐：价格呢？市场上白条现在17.9，你们别报太高。
小王：17.9是散户价，我们给您报18.2，但整只白条当天现杀，损耗低，算下来不比散户贵。
刘姐：那我切好的分割品呢？我早上没时间切。
小王：可以，我们按您要的规格提前切好送来，分割费每公斤加3毛。您这周要几头？我先安排一辆小厢货试送。
```
