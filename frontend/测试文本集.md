# 客户经理 AI 作战台 · 测试文本集

> 用法：拜访助手 → 粘贴文本 → 点「生成总结」（后端在线时走真实 Agent）；找客户 → 粘贴新客文本 → 点「生成开发方案」（配合滞销品承接填 `白条` 可测地图标注）。数据看板 / 成功记忆库随拜访记录自动联动。

## ① 新客开发 · 餐饮客户（相似案例 / 找客户）
> 标签：新客开发｜相似成功案例｜找客户

```
今天首次拜访郑州餐饮连锁客户李总，做连锁快餐，需要分割品，最担心出成率和到货稳定，当前有固定供应商，想先看看我们的配送时效再做决定。
```

## ② 报价沟通 · 竞品比价 + 账期（比价表 / 综合价差 / 账期风控）
> 标签：报价沟通｜竞品比价｜综合价差｜账期风控

```
今天拜访南阳批发客户张老板谈报价。客户说温氏白条走18.6，给30天账期；新希望猪前腿给到20.4元。客户希望我们白条给到19.2，账期月结30天，说价格合适就长期合作。
```

## ③ 质量投诉处理（投诉闭环 / P0 待办）
> 标签：质量投诉｜P0 待办｜风险提醒

```
今天处理许昌商超客户的客诉。客户反馈上周到货的白条有一批色泽发暗、出成率低，要求赔付并整改。客户说如果再出现质量问题就考虑换供应商。已约本周五到现场核实批次和证据。
```

## ④ 老客复购 · 成功记忆自动沉淀
> 标签：老客复购｜成功记忆沉淀｜相似案例

```
今天回访洛阳商超客户，上次小批量试单的鲜品走货很好，损耗低，客户说想继续合作，本月加量到两吨，下个月可能再翻一倍。客户主要做商超和农贸档口，最关心配送时效和品质稳定。
```

## ⑤ 账期高风险 · 催收待办
> 标签：账期极高风险｜P0 催收｜逾期预警

```
今天催收驻马店批发客户，客户已经失联两周，电话不接，还欠着上次货款八万五，逾期45天，说下个月再结。客户说最近生意不好做，考虑转让店面。
```

> 标签：售后回访｜复购信号

```
今天回访周口团餐客户确认上次投诉处理结果。客户说赔付和整改都到位了，服务态度满意，愿意恢复合作，约定下周送一批分割品试用。
```

## ⑦ 滞销品承接 · 地图标注
> 标签：找客户｜滞销承接｜地图标注
> 配合找客户「滞销品承接」填 `白条B规格`，可在河南地图上看到紫色「滞销承接」标记。

```
今天拜访开封农贸档口客户，客户做白条批发，日销量大，周转快，能接受短周期促销，最关心价格和到货稳定。客户目前没有固定供应商，正在多家比价。
```

## ⑩ 多人对话（客户经理 + 客户 + 采购）
> 标签：对话识别｜账期+欠款｜比价｜质量反馈
> 多人对话实测：DeepSeek 能正确区分"谁说的"，识别出 加量2吨 / 30天账期 / 3.5万欠款 / 温氏18.6 / 色泽出成率问题，并生成对应待办。

```
客户经理小王回访南阳批发客户张老板，店里采购小李也在场。
小王：张老板，上次那批白条走货怎么样？
张老板：走货还行，就是损耗比我想的高一点。
小李：主要是最后那两天到货的，色泽有点暗，出成率低了些。
张老板：小王你也别光听好话，上次说好的30天账期，怎么还没批下来？我们这边一直想续量，你这个月能不能把量加到两吨？
小王：账期的事我回去再跟公司确认，您放心。不过咱们上次那三万五的货款还没结，张老板您看这周能不能先结一部分？
张老板：最近手头确实紧，等月底客户回款了我就结，不骗你。
小李：对了王哥，温氏那边白条报18.6，还给30天账期，你们公司能不能也按这个价走？
小王：价格我可以再谈，但我们的品质和到货稳定摆在这。您先按主销规格做个试单，我下周先把配送时效的对比数据给您送过来。
张老板：行，那这个月先把量加到两吨，你尽快把报价单发我，账期的事一起落实。
```
